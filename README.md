# T2Sisop

O trabalho implementa um SO didático com CPU, memória física, paginação por demanda, tratamento de faltas de página (page fault), dispositivo de disco e console de E/S, escalonador preemptivo por timer e modo contínuo (thread de escalonamento). O kernel expõe uma CLI com comandos para criação/remoção de processos, execução, inspeção e depuração.
